## 1. 打包结构（关键发现）

Tauri 2 把整个前端塞进 PE 的只读数据区，格式是**紧邻拼接**：

```
[ 路径字符串（ASCII，无 \0 结尾） ][ brotli 压缩流 ][ 下一个路径 ][ brotli 流 ] ...
```

- 路径形如 `/assets/main-DWII-cul.js`、`/index.html`
- 压缩流紧跟路径最后一个字节，**无长度前缀**，靠 brotli 流自身的 ISLAST 位结束
- 因此解包只需：在二进制里扫 `/assets/...`、`/index.html`，从路径末尾开始 `brotliDecompressSync` 即可

## 7. 本地凭据与清理

- DPAPI 只用于**自己**的登录态：`com.csmatchhelper.desktop/perfect-auth/settings-v1` +
  `"CS Match Helper login credential"`，按当前用户 SID 绑定（`cannot open the current Windows user token`）。
- `decrypt_perfect_response` 解的是接口返回的加密信封（`envelope/base64/key_length/padding`），不是客户端 Cookie。
- 没有 `Cookies`/`leveldb`/完美客户端目录读取代码。

**旧版 HUD 清理**（4.0.2 只保留“删残留”，不再写 GSI）：

```text
读 libraryfolders.vdf / appmanifest_730.acf 定位 CS 目录
删 common\csgo\cfg\gamestate_integration_cs_match_helper.cfg
powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -Command
  Get-AppxPackage -AllUsers -Name CSMatchHelper.GameBarWidget | Remove-AppxPackage
  （CounterStrafingHudWidget 同理）
写 legacy-hud-cleanup.log / legacy-hud-cleanup-v1.json
```
