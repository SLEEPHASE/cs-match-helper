## 为什么可以原地换

Tauri 2 资源表是 `.rdata` 里 25 条定长 32 字节条目：

```
[u64] key_ptr → "/assets/main-DWII-cul.js"
[u64] key_len
[u64] data_ptr → 紧跟路径的 brotli 流
[u64] data_len
```

`data_ptr` 在重定位表里（DIR64），换值后 ASLR 仍然正确。

流程：

1. `tools/pack_frontend.mjs`：`sleephase-extras.js` + `sleephase-custom.js` 前置进 main bundle（`try{}catch{}` 包一层），index.html 去掉 extras 引用，两份 brotli q11
2. `tools/repack_pe.py`：新增 `.adata` 节，改两个条目的 `data_ptr/data_len`，同步 `NumberOfSections`/`SizeOfImage`
3. `tools/patch_version.py`：`4.0.2 → 1.0.0`
4. `tools/strip_admin.py`：给 no-admin 版换清单

## 复现

```powershell
node tools\pack_frontend.mjs frontend build\repack
python tools\repack_pe.py <原版.exe> build\stage1.exe build\repack\manifest.json
python tools\patch_version.py build\stage1.exe dist\out.exe
python tools\strip_admin.py dist\out.exe dist\out-no-admin.exe
python tools\verify_pack.py dist\out.exe build\verify
```

## 注意

- 资源表不支持**追加**条目，所以新增逻辑只能内联进主包，不能作为独立 `assets/*.js`。
- 更新检查走前端拦截，后端里沉睡的 `cdn.lunaris.win` 字符串没删（不参与 UI 流程）；要让后端也彻底换，得重建（`backend/`，需 Rust）。
- 重打包后 PE 校验和失效（未签名不影响运行）；因为改了资源，杀软可能多看两眼。
- 启动密码只是 UI 闸门（前端），能挡住普通使用者，不是加密。
