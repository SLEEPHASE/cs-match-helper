## 1. 三个全局入口

| 锚点 | 作用 |
|---|---|
| `async function J(e,t={},n){return window.__TAURI_INTERNALS__.invoke(e,t,n)}` | 唯一的后端调用入口，所有命令都走它 |
| `function U(e,t){…}` | 双语选择器：`U('中文','English')`，按当前 locale 返回 |
| `R.global.locale.value` | Vue i18n 全局 locale（`zh-CN` / `en-US`） |

## 2. API 层（约 offset 222 000 起）

一整段 `async function xx(e){return J(\`cmd\`,{...})}`，命令与参数一一对应：

```
m_  get_log_status            h_  read_latest_log_lines      g_  start_log_watch
__  stop_log_watch            v_  fetch_perfect_player_stats  …
Sp  launch_5e_with_cdp        Cp  probe_5e_cdp_active         wp  start_5e_cdp_collector
Tp  stop_5e_cdp_collector     Ep  get_5e_cdp_status           Dp  set_5e_cdp_gate_debug_mode
sw  list_match_history_documents   cw  get_match_history_entry
lw  upsert_match_history_entry     uw  patch_match_history_section
```

> 想加一个后端命令：在 API 层加 `async function x(a){return J(\`my_cmd\`,{a})}`，再到「新建 Tauri 命令」里注册同名命令即可。

## 6. 常见魔改的落点

| 目标 | 落点 |
|---|---|
| 改应用名 / 副标题 | `index.html` `<title>`；`Um.common.appName`；`document.title` 逻辑 `nh()` |
| 改界面文案 | `tools/i18n/zh-strings.json` → `apply_strings.mjs` 批量替换 |
| 改主题色 | `main-*.css` 里的 `--color-*` / Tailwind 变量；或 `index.html` 的 `background-color` |
| 加一列数据 | 列定义数组 `ck`/`ak` + 表格渲染分支（搜 `key===\`clutchWinRate\``） |
| 关掉 5E 入口 | `MatchFeaturedPanel`/导航里的 `platformId===`5e`` 分支；或运行时拦截（见 mod 指南） |
| 换 AI 供应商 | `AI_PROVIDER_OPTIONS` + `baseUrl` + `model` |
| 去掉更新检查 | `check_for_update` 调用点；或直接改后端返回 |
| 换图标 | `assets/*.png|svg` + `backend/icons/icon.ico` |
