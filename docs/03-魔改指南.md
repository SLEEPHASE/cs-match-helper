# 魔改指南（三条路线，从快到彻底）

> 前提：`frontend/` 是已解包的前端，`backend/` 是重建的 Tauri 2 后端骨架。
> 原始 exe 里的前端是 **brotli 定长内嵌**，不能简单替换文件，所以只有“重建”或“运行时注入”两条路。

---

## 路线 A：运行时注入（0 构建，改完立刻看效果）

原理：WebView2 支持 `--remote-debugging-port`，注入 JS 后可以包 `__TAURI_INTERNALS__.invoke`、改 DOM。

```powershell
# 1) 启动原版 exe + 注入示例 mod（UAC 点“是”）
node tools\mod_loader.mjs --exe "C:\path\cs-match-helper.exe" --patch tools\patches\example-mod.js

# 2) 只关 5E 链路（打完美时最稳）
node tools\mod_loader.mjs --exe "C:\path\cs-match-helper.exe" --patch tools\patches\no-5e.js --port 9333

# 3) 已经开着程序，直接附加
node tools\mod_loader.mjs --attach --port 9333 --patch tools\patches\example-mod.js
```

`example-mod.js` 里已经演示了四件事：

```js
// ① 拦截任意命令
internals.invoke = async (cmd, args, opts) => { ... }

// ② 改返回值（版本号、假数据、解锁开关）
if (cmd === 'get_app_version') return { version: '9.9.9' }

// ③ 改 DOM / 文案 / 加徽标
document.title = 'CS 匹配助手 · MOD'

// ④ 监听后端事件（AI 流式、对局推送）
internals.event.listen('ai-analysis-delta', cb)
```

> 注入脚本在页面刷新后会丢，`mod_loader` 已经挂了 `Page.loadEventFired` 自动重注入。

## 路线 B：前端重打包（改文案 / 样式 / 布局）

`frontend/` 就是完整 dist，改完直接作为 `frontendDist` 用。

```powershell
# 1) 导出文案清单（828 条中文片段）
node tools\dump_strings.mjs frontend\assets\main-DWII-cul.js tools\i18n\zh-strings.json

# 2) 写映射表
@'
{ "CS 匹配助手": "MyHelper", "完美平台账号": "完美账号", "小淳": "me" }
'@ | Set-Content tools\i18n\rename.json -Encoding utf8

# 3) 批量替换（先 --dry 看命中数）
node tools\apply_strings.mjs frontend\assets\main-DWII-cul.js tools\i18n\rename.json frontend\assets\main-DWII-cul.js --dry

# 4) 正式替换
node tools\apply_strings.mjs frontend\assets\main-DWII-cul.js tools\i18n\rename.json frontend\assets\main-DWII-cul.js
```

i18n 双语表（`tools/i18n/zh-CN.json`、`en.json`）对应 bundle 里的 `Um` / `Hm` 两个对象，改完用
`tools\dump_i18n.mjs` 的逆过程（把 JSON 序列化回字面量替换 `Um={…}` / `Hm={…}`）即可。

调色/排版：直接改 `frontend/assets/main-Dpi9KsYW.css`（Tailwind 产物，`--color-*` 变量集中在头部）。

## 路线 C：整体重建（改功能逻辑，唯一能改后端的方式）

```powershell
cd backend
# 需要 Rust + MSVC Build Tools + WebView2 Runtime
rustup default stable
cargo install tauri-cli --version "^2"
cargo tauri dev      # 开发
cargo tauri build    # 出安装包
```

`backend/src` 已按原始命令表铺好 52 个 `#[tauri::command]`，事件通道同名同参；
平台相关（完美 / 5E）留了 `platform/*.rs` 供你对接。

**改功能的最小闭环**：

1. 后端加命令

```rust
#[tauri::command]
async fn my_cmd(state: State<'_, AppState>, foo: String) -> Result<Value, String> {
    Ok(json!({ "echo": foo }))
}
// main.rs: .invoke_handler(tauri::generate_handler![..., my_cmd])
```

2. 前端加一行

```js
async function myCmd(foo){ return J(`my_cmd`, { foo }) }
```

3. 顺带把窗口配置改了：`backend/tauri.conf.json`（宽高、标题、是否置顶、是否透明）。

## 新功能：深色模式 + 准备顺序

两者都在 `frontend/assets/sleephase-extras.js` 里，`index.html` 用一条 `defer` 引入：

```html
<script defer src="./assets/sleephase-extras.js"></script>
<script type="module" crossorigin src="./assets/main-DWII-cul.js"></script>
```

必须排在主模块**之前**，否则应用启动后的第一批 IPC 数据会被漏掉（只影响准备顺序）。

### 深色模式

- 三态：`system` / `light` / `dark`，默认 `system`
- 标题栏按钮（插在窗口控制按钮左侧）+ `Ctrl+Shift+L`
- `localStorage['csmh.theme']` 记忆；`prefers-color-scheme` 变化时自动跟随
- 切换时给 `<html>` 加 280ms 的 `theme-anim`，只过渡颜色，不触发布局

想改配色只改这一段：

```css
html[data-theme="dark"]{
  --color-base:#0b1017; --color-surface:#111823; --color-elevated:#18212e;
  --color-fg:#e9eff8;   --color-border:#25344a; --color-accent:#5aa2f0;
  --color-slate-50:#0d141d; … --color-slate-700:#ccd8e5;
}
```

`slate-800/900/950` 刻意不反相（遮罩/浮层要深），对应文字用 `.text-slate-800/900/950` 单独提亮。

### 准备顺序

面板固定在左下角，列出 `1 / 2 / 3 …` + 昵称 + 相对首个准备的耗时，超出滚动，点标题折叠。

数据来源是应用本身已有的字段，不新增后端：

```
readyUuids / readyMembers / ready_members / readyPlayerIds / readySteamIds   （数组）
ready_player_id / readyPlayerId / ready_steam_id / readySteamId              （单条）
players / unassigned / members                                              （昵称反查）
```

同一 `matchId/platformGameId` 内去重；检测到换局自动清空。一次 payload 内的顺序先入缓冲，
批次结束再提交，避免 `matchId` 字段排在 `readyUuids` 后面时把刚记的顺位清掉。

注入版（给原版 exe 用）只从注入时刻开始记录：

```powershell
node tools\mod_loader.mjs --exe "C:\path\cs-match-helper.exe" --patch tools\patches\theme-ready-order.js
```

## 高危功能处置（PAC / 5E 视角）

| 功能 | 原始实现 | 建议 |
|---|---|---|
| 5E 调试端口 | kill `5EClient` → `--remote-debugging-port` → CDP 抓 `view-arena` | 重建版默认关闭；运行版用 `no-5e.js` 拦掉 |
| 管理员常驻 | 清单 `requireAdministrator` | 改成 `asInvoker`，只在启动 5E 时提权 |
| PowerShell 清理 | `-ExecutionPolicy Bypass` + `Remove-AppxPackage -AllUsers` | 换 WinRT `PackageManager`，或安装器一次性做 |
| 游戏内覆盖窗口 | `set_content_protected` + 置顶/穿透 | 不要与游戏同屏；改第二屏/网页 |

去管理员清单（只改本地副本，PE 校验会变，签名已无）：

```powershell
python tools\strip_admin.py "C:\path\cs-match-helper.exe" "C:\path\cs-match-helper.no-admin.exe"
```
